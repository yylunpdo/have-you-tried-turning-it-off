A [make.fun](https://make.fun) bounty entry: one funny single-line reply,
under 200 characters, from a hopeless tech support agent to a desperate
customer. The agent's only trick is turning it off and on again — and he
casts that spell like it might actually work this time.

## How it works

`main.py` (pure Python stdlib, no dependencies) writes the line to
`/output/entry.txt`:

> Have you tried turning it off and on again? It's the only spell I know,
> and I cast it like it might actually work this time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
